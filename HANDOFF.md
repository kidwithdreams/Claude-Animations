# Передача контекста: переход на Blender (Windows + NVIDIA)

Этот файл для новой сессии Claude Code на компьютере пользователя. Прочитай его целиком перед работой.

## Что уже сделано (облачная сессия)
Канал коротких вертикальных роликов (9:16, 1080×1920, 30 fps) с английской озвучкой из ElevenLabs.

| Папка | Ролик | Стиль / движок |
|---|---|---|
| `onions/` | Why Onions Make You Cry (32 с) | Zack D. Films, three.js (skill `zach-d-films`) |
| `stuck/` | STUCK, хоррор-выживание (1:52) | плоская 2D-анимация на canvas |
| `knuckles/` | Why Do Knuckles Crack? (28,6 с) | Zack D. Films, three.js |

Во всех проектах одинаковый пайплайн:
1. **Озвучка:** пользователь присылает mp3 из ElevenLabs, конвертируем в `audio/vo.wav` (моно, 44,1 кГц).
2. **Тайминги слов:** Parakeet через sherpa-onnx (`kit/words.py` из репозитория `artemnovitckii/claude-animation-skills`), со сценарием `script.json` для правильного написания слов.
3. **Субтитры:** крупные, белые, Montserrat 900 с чёрной обводкой, 1–3 слова, по таймингам.
4. **Сцены:** новая картинка каждые 1,5–3 с, склейки по словам. Каждый кадр проверяется на стоп-кадрах до полного рендера.
5. **Звук:** SFX и тихая музыкальная подложка генерируются кодом (numpy/scipy, см. `*/audio_mix.py`), подложка приглушается под голосом. Голос в речевой полосе должен быть на 6+ дБ громче всего остального. Громкость около -14 LUFS.
6. **Склейка:** ffmpeg, H.264, AAC.

## Почему Blender
Движок three.js в облаке упирается в мультяшную картинку и медленный софтверный рендер (5–10 с на кадр). Цель — ближе к Zack D. Films: настоящий свет, кожа с подповерхностным рассеянием, размытие в движении, нормальные персонажи с мимикой. Рендер на GPU пользователя (NVIDIA, OptiX).

## Решения, о которых договорились
- **Персонаж:** MPFB2 (бесплатный аддон Blender, лицензия позволяет коммерческое использование). У него сразу есть скелет и формы лица (выражения, рот для речи). Стилизовать под Zack D. Films: голова чуть крупнее, гладкая кожа, яркий студийный свет, голубое «небо»-фон.
- **Анимации тела:** Mixamo. Пользователь сам загружает персонажа (Upload Character) и скачивает анимации, в аккаунт Adobe заходить не нужно.
- **Губы под озвучку (если нужно):** Rhubarb Lip Sync (бесплатно, по аудио).
- **Управление Blender:** blender-mcp для сборки сцен и превью. Финальный рендер можно запускать без окна: `blender.exe -b файл.blend -P скрипт.py`.

## Первые шаги новой сессии
1. Проверить, что blender-mcp подключён (`/mcp`), а Blender видит GPU (Preferences, System, OptiX).
2. Поставить MPFB2, сделать первого персонажа, показать пользователю рендер.
3. Сделать тестовую сцену на 3–5 секунд (студийный свет, персонаж, камера), отрендерить через Cycles на GPU, показать.
4. Потом перенести пайплайн субтитров и звука (Python + ffmpeg) на Windows. Модели для таймингов слов ставятся через `kit/setup.sh --voice` в репозитории claude-animation-skills (на Windows запускать через Git Bash или переписать команды).
